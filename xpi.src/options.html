Settings

Logging

Log detailed information to the browser console for troubleshooting

Behavior

Automatically switch to the sticky tab when a URL is redirected to it Default for rules set to "Use default". Closing one protected sticky tab is undone. Closing its window, or quitting Firefox, is not blocked.

Sync

Sync your rules and the sticky close-protection default across devices using your Firefox Account. Requires Firefox Sync to be enabled.
